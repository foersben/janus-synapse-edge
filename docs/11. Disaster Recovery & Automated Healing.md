# 11. Disaster Recovery & Automated Healing

Because the server operates without a UPS, it is guaranteed to experience ungraceful shutdowns. This layer ensures that when power returns, the system cleans up its own mess without manual SSH intervention.

## 1. The ZFS Unlock & Boot Sequence (Human-in-the-Loop)

Because the Proxmox host is secured with Zero-Trust ZFS Native Encryption, it is fundamentally impossible for the server to boot unattended after a power outage.

* **The WOL Trigger:** When the grid stabilizes, the UPS-backed Intel NUC sends a Wake-on-LAN packet. This merely powers on the main server's motherboard.
* **The Air-Gap Prompt:** The server will halt at the Proxmox bootloader, waiting for you to physically plug in a USB keyboard and type the decryption passphrase.
* **The Handoff:** Once you manually unlock the drive, the Talos VMs boot, K3s initiates (pulling the `etcd` snapshot from the Intel NUC if necessary), and the Python Janitor Daemon automatically takes over to heal the software corruption caused by the ungraceful shutdown.

## 2. The Python Janitor Daemon

This is a lightweight Python script running as a Kubernetes CronJob (or as a background task in n8n) that acts as the system's "cleanup crew."

**The Boot-Up Sweep:**

1. Once the LiteLLM proxy reports as healthy, the Janitor Daemon pings Intel NUC database.
2. It queries the Agent Ledger: *"Give me all tasks marked `PENDING` or `RUNNING`."*
3. Because the server just booted, any task listed as `RUNNING` is mathematically guaranteed to have been killed mid-execution by the power outage.

**The "Nuke & Pave" Rollback:**
For every stranded task (e.g., Task 104), the Janitor executes the recovery protocol:

1. **Destroy:** It forcefully deletes the ephemeral Docker/LXC sandbox associated with Task 104. All corrupted, half-written files are vaporized.
2. **Reset:** It resets the ledger status on the NUC from `RUNNING` back to `QUEUED`.
3. **Notify:** It injects a system prompt into Agent Zero's memory context: *"System recovered from power failure. Task 104 failed mid-execution. A clean sandbox has been provisioned. Please resume."*

By pairing the NUC's infallible memory with the Janitor's ruthless sandboxing destruction, the AI completely recovers from sudden death with zero manual code tracking
