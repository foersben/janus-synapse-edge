# 01. Physical Assembly, BIOS & Bare-Metal Security

## 1. Physical Assembly Clearances (Jonsbo Z20)

* **GPU & PSU Collision:** The ZOTAC RTX 5070 Ti is exactly 303.5mm long. The ASUS ROG Loki SFX-L PSU **must** be mounted at the highest possible P-level in the front bracket to prevent the PSU cables from colliding with the GPU backplate.
* **PSU Orientation:** The 120mm RGB fan of the Loki PSU must face the right-side mesh panel to intake fresh outside air.
* **NVMe Thermal Armor:** The 2TB FireCuda 530 must be installed in the top `M2_1` slot. Use the motherboard's built-in silver heatsink rather than a third-party one to ensure perfect clearance under the Thermalright PA120 SE CPU cooler.
* **Airflow Logic:** Bottom 120mm fans (Intake) -> Rear 120mm Reverse-blade (Intake) -> Top 140mm HAVN fans (Exhaust).

## 2. BIOS Thermal Tuning & Undervolting (Taming the 14700K)

Under full load, the 14700K will attempt to draw 280W. Inside the Jonsbo Z20, this will cause the CPU to hit 100°C instantly.

  * **Step 1:** Boot into the ASRock BIOS (F2 or DEL).
  * **Step 2 (Power Cap):** Navigate to `OC Tweaker -> CPU Configuration`. Hard-cap PL1 and PL2 to **180W**.
  * **Step 3 (Undervolting):** Navigate to the Voltage Configuration menu. Apply a **Negative Core Voltage Offset** (Start with `-0.050V` and test stability).
  * **Result:** Undervolting allows the CPU to maintain significantly higher clock speeds and push more instructions while remaining trapped safely beneath your 180W ceiling, clawing back lost performance without raising ambient case temperatures

## 3. BIOS Virtualization & IOMMU (Required for K3s)

To pass the RTX 5070 Ti directly to the Kubernetes VM, hardware virtualization must be absolutely unrestricted.

* **Step 1:** Navigate to `Advanced` -> `CPU Configuration`. Enable **Intel Virtualization Technology (VT-x)**.
* **Step 2:** Navigate to `Advanced` -> `System Agent (SA) Configuration`. Enable **VT-d (Intel IOMMU)**.

## 4. Bare-Metal Anti-Theft Mitigations

Because consumer motherboards lack enterprise RAM encryption (MKTME), physical mitigations are required to prevent data extraction from a running server.

* **Disable Unused DMA Vectors:** In the BIOS `Advanced` menus, explicitly disable any unused PCIe slots, secondary M.2 slots, and unused internal USB headers. This prevents a thief from plugging in a specialized DMA (Direct Memory Access) device to scrape decryption keys directly out of the DDR5 RAM while the server is powered on.
* **Chassis Intrusion Header:** (Optional but recommended). Connect the Jonsbo side-panel switch to the ASRock motherboard's Chassis Intrusion pins. Later, this will be tied to a Proxmox trigger to immediately kill power or wipe RAM if the case is opened.

## 5. Surge Protection & The "Stay Off" Protocol (No-UPS Mitigation)

Without a UPS, the server is highly vulnerable to the massive voltage spikes that occur when the city grid restores power after an outage.

* **Hardware Protection:** Do not plug the server into the wall or a cheap power strip. Use a dedicated high-end surge protector (e.g., Brennenstuhl Premium-Protect-Line, rated for 60,000A+). The MOVs inside will sacrifice themselves to absorb grid spikes before they hit the ASUS Loki PSU.
* **The BIOS "Stay Off" Rule:** When the grid comes back online, power is often "dirty" (fluctuating). The server must not attempt to boot into this chaos.
  * In the ASRock BIOS, navigate to Advanced -> ACPI Configuration.
  * Find `Restore on AC/Power Loss` and set it strictly to **Power Off**.
  * *Result:* The server receives power but remains entirely dormant until you manually turn it on or the NUC sends a Wake-on-LAN magic packet once it verifies network stability
* **Switch Topology:** The **NETGEAR MS308E** must be plugged into the Eaton 3S 550 DIN UPS alongside the NUC. This ensures that during a power outage, the network path remains alive for the NUC to send the Wake-on-LAN packet once grid power returns.
