# Physical Assembly, BIOS & Bare-Metal Security

The foundational layer of the Janus cluster is physical hardware integration and low-level firmware configuration. Because consumer-grade hardware lacks the inherent physical security and thermal headroom of enterprise blade servers, these mitigations must be manually engineered into the assembly and BIOS phases.

!!! abstract "The Hardware-Firmware Boundary"
    The objective of this phase is threefold: to guarantee physical clearances within the Micro-ATX chassis, to restrict the thermal envelope of the CPU without catastrophic performance degradation, and to harden the bare-metal firmware against direct memory access (DMA) attacks and grid instability.

---

## 1. Physical Assembly Clearances and Component Integration (Jonsbo Z20)

Building an enterprise-grade AI cluster inside a 20-liter Micro-ATX chassis requires absolute spatial and thermal precision. Because the primary compute node operates under sustained heavy workloads (e.g., local model tuning and high-concurrency inference), each component must be integrated to prevent physical interference and maximize thermal efficiency.

### 1.1 CPU Socket and Thermal Interface Modulation (The CPU Mod)

The stock Intel Independent Loading Mechanism (ILM) on the LGA1700 socket applies highly concentrated pressure near the center of the CPU integrated heat spreader (IHS). Under the high thermal cycles of the i7-14700K, this uneven mechanical force causes the CPU substrate and IHS to warp (flex), creating a concave mating surface. This bowing creates an air gap or thick thermal paste layer between the IHS and the cooler base, significantly degrading thermal transfer efficiency and leading to premature thermal throttling.

```text
       [ Bowed IHS under Stock ILM ]                  [ Flat IHS with Contact Frame ]
          +-----------------------+                      +-----------------------+
          |  CPU Cooler Base (Flat|                      |  CPU Cooler Base (Flat|
          +-----------------------+                      +-----------------------+
             \  Thick Paste Gap /                           || Thin, Even Paste ||
          +---==============------+                      +---====================+
          |     Bowed IHS         |                      |       Flat IHS        |
          +-----------------------+                      +-----------------------+
```

To resolve this constraint:

1. **Contact Frame Retrofit:** The stock ILM is completely removed and replaced with a **Thermal Grizzly** or **Thermalright LGA1700 Contact Frame**. This frame redistributes clamping force evenly along the entire perimeter of the CPU substrate, ensuring a perfectly flat IHS mounting surface.
2. **Thermal Interface Material:** **Gelid GC-Extreme Thermal Paste** is applied. Highly viscous and containing optimized nano-conductive particles, Gelid GC-Extreme does not experience thermal pump-out under rapid temperature cycles, ensuring a long-lasting, low-resistance thermal bridge to the CPU cooler.
3. **CPU Cooler Mounting:** The **Thermalright Peerless Assassin 120 SE (PA120 SE) White ARGB** dual-tower cooler (155mm height) is mounted directly to the contact frame. The dual-tower fins align parallel to the chassis airflow vector, drawing fresh ambient intake directly from the rear.

### 1.2 Memory Topography and Channel Allocation

To sustain high-throughput memory offloading during llama.cpp deep reasoning verification passes, the **128 GB Crucial DDR5 Kit** must operate with absolute signal integrity. High-density, dual-channel DDR5 is highly sensitive to trace length reflections and electrical noise.

* **Slot Selection:** The memory modules must be installed exclusively in motherboard slots **A2 and B2** (slots 2 and 4 from the CPU socket). Populating these specific slots ensures optimal termination impedance and prevents signal degradation that occurs when using the primary slots (A1/B1) on daisy-chain motherboard topologies.

### 1.3 NVMe Storage Substrate & MC1 Cooler Clearance

The primary storage tier consists of a **2TB Seagate FireCuda 530 Gen4 NVMe SSD** utilizing premium TLC NAND, a 2GB DRAM-cache, and the Phison E18 controller, capable of sustaining 2,550 TBW endurance.

* **Mounting Protocol:** The drive is installed in the top **M2_1** slot, which is directly connected to the CPU's dedicated Gen4 PCIe lanes.

* **Clearance Strategy:** To prevent physical interference with the low-hanging fins of the PA120 SE CPU cooler, the drive is equipped with a low-profile **be quiet! MC1 M.2 SSD Cooler**. This compact, highly efficient heatsink provides superior passive thermal dissipation for the Phison E18 controller under heavy, sustained read/write cycles while ensuring perfect spatial clearance beneath the cooler tower.

### 1.4 GPU Spatial Envelope and PSU Clearance Constraints

The **ZOTAC GAMING GeForce RTX 5070 Ti SOLID CORE** (or SOLID CORE OC), built on the NVIDIA Blackwell (SM120) architecture, features a high-density 2.5-slot cooling shroud and an exact physical length of **303.5 mm**.

* **The Spatial Collision Risk:** In the compact Jonsbo Z20 chassis, the power supply is mounted in a modular bracket at the front of the case. A GPU length of 303.5 mm extends directly into the path where the PSU cables exit the power supply housing.

* **Mitigation Strategy:** The **ASUS ROG Loki SFX-L 850W/1000W** PSU must be installed at the **highest possible position (P-level)** within the Jonsbo front mounting bracket. This elevates the cable exit point above the level of the GPU backplate, routing the modular cables directly downward and avoiding physical collision or extreme cable bending against the end of the graphics card.

### 1.5 Power Supply (PSU) Integration

The **ASUS ROG Loki SFX-L** is a compact ATX 3.0 power supply utilizing a single native 16-pin 12V-2x6 PCIe 5.0 cable to deliver clean power directly to the Blackwell GPU.

* **Orientation Protocol:** The PSU's 120mm RGB intake fan must face the **front side panel** (which features a mesh grid). This enables the PSU to pull fresh ambient air directly from outside the chassis, operating in its own isolated thermal loop, rather than drawing in pre-heated air from the internal CPU/GPU chamber.

### 🌬️ Thermal Airflow Dynamics and Fan Topography

To combat the highly restricted thermal envelope of the Jonsbo Z20 under sustained 500W+ combined loads, the system employs a positive-pressure, bottom-to-top and rear-to-front airflow configuration. This forces cool ambient air directly over critical heat zones before exhausting out the top.

#### Detailed Fan & Connection Grid

1. **Bottom Intake:** **2x Noctua Slim 120mm fans** are mounted on the bottom panel. They are connected via a PWM Y-cable to the motherboard header **CHA_FAN2**. These fans pull cool ambient air from beneath the chassis and blow it directly into the ZOTAC RTX 5070 Ti's intake shroud.
2. **Rear Intake:** **1x ARCTIC P12 Pro Reverse A-RGB White 120mm fan** is installed as a rear intake. By utilizing a reverse-blade design, the aesthetic hub faces inward while drawing fresh ambient air from the rear of the case directly onto the fins of the PA120 SE CPU cooler. It is connected directly to the motherboard's PWM and 5V ARGB headers, with the BIOS configured to activate **0dB mode below 5% PWM** for silent operation during low-load idle phases.
3. **Top Exhaust:** **2x HAVN H14 140mm fans** are mounted on the top panel. Daisy-chained together via an integrated loop cable and connected to the motherboard header **CHA_FAN1**, these high-airflow fans rapidly exhaust hot air out of the top of the chassis.

## 2. BIOS Thermal Tuning (Taming the 14700K)

Under full load, the Intel Core i7-14700K will attempt to draw over 280W. Inside the Jonsbo Z20, this will cause the CPU to hit 100°C instantly, leading to severe thermal throttling during long AlphaEvolve training runs.

!!! tip "The Undervolting Strategy"
    Undervolting allows the CPU to maintain significantly higher clock speeds and push more instructions while remaining trapped safely beneath your wattage ceiling. You claw back lost performance without raising ambient case temperatures.

**Implementation Protocol:**
1.  **Boot into the ASRock BIOS** (F2 or DEL).
2.  **Power Cap:** Navigate to `OC Tweaker -> CPU Configuration`. Hard-cap **PL1 and PL2 to 180W**.
3.  **Undervolting:** Navigate to the `Voltage Configuration` menu. Apply a **Negative Core Voltage Offset** (Start with -0.050V and test for stability using stress tests before moving to production).

## 3. BIOS Pre-Flight & Initialization

To ensure headless operation, hardware virtualization, and the successful compilation of custom early-boot cryptographic hooks, the motherboard firmware must be strictly configured before OS installation.

1.  **Secure Boot: DISABLED.** The architecture relies on custom `zfs-dkms` kernel modules and unsigned `initramfs` hooks. Leaving Secure Boot enabled will block the OS from booting unless you manually provision MOK keys.
2.  **Fast Boot: DISABLED.** Ensures full USB initialization and prevents the system from skipping the GRUB boot menu timeout.
3.  **Primary Graphics Adapter: AUTO / PEG.** Ensures the system does not force integrated graphics when operating headlessly without a monitor attached.
4.  **Virtualization (VT-x & VT-d): ENABLED.** Navigate to `Advanced -> CPU Configuration` to enable Intel VT-x. Then, navigate to `Advanced -> System Agent (SA) Configuration` to enable VT-d (Intel IOMMU). This is critical for passing the RTX 5070 Ti directly to the AI Pods.

## 4. Bare-Metal Anti-Theft Mitigations

Because consumer motherboards lack enterprise RAM encryption (like Intel MKTME or AMD SME), physical mitigations are required to prevent data extraction from a running server.

!!! warning "Zero-Trust Physical Layer"
    If an attacker gains physical access to a running machine, they can use specialized PCIe hardware to scrape decryption keys directly from the RAM.

*   **Disable Unused DMA Vectors:** In the BIOS Advanced menus, explicitly disable any unused PCIe slots, secondary M.2 slots, and unused internal USB headers. This prevents a thief from plugging in a Direct Memory Access (DMA) device.
*   **Chassis Intrusion Header:** (Optional but recommended). Connect the Jonsbo side-panel switch to the ASRock motherboard's Chassis Intrusion pins. Later, this can be tied to a Proxmox trigger to immediately kill power or wipe RAM if the case is opened while armed.

## 5. Surge Protection & The "Stay Off" Protocol

Without a UPS on the main compute node, the server is highly vulnerable to massive voltage spikes that occur when the city grid restores power after an outage.

### 🔌 Power & Recovery Topology

```mermaid
graph TD
    Grid((City Grid Power)) -->|Unstable / Spikes| Surge[Brennenstuhl Surge Protector\n60,000A Rating]
    Grid -->|Standard AC| UPS[Eaton 3S 550 DIN UPS]

    Surge -->|Filtered Power| PSU[Main Server PSU]
    PSU -->|BIOS 'Stay Off' Rule| Main[Main Node: 14700K / 5070 Ti\nRemains Dormant]

    UPS -->|Battery Backed| NUC[Edge Node: Intel NUC\nClickHouse Telemetry]
    UPS -->|Battery Backed| Switch[NETGEAR MS308E\n2.5G Managed Switch]

    NUC -.->|Detects Network Stability| MagicPacket{Wake-on-LAN Packet}
    Switch -.->|Routes WOL| MagicPacket
    MagicPacket -.->|Triggers Boot| Main

    style Surge fill:transparent,stroke:#333,color:#fff
    style UPS fill:transparent,stroke:#333,color:#fff
    style Main fill:transparent,stroke:#333,color:#fff
    style NUC fill:transparent,stroke:#333,color:#fff
```

### Protocol Implementation

1. **Hardware Protection:** Do not plug the server into the wall or a cheap power strip. Use a dedicated high-end surge protector. The MOVs inside will sacrifice themselves to absorb grid spikes before they hit the ASUS Loki PSU.
2. **The BIOS "Stay Off" Rule:** When the grid comes back online, power is often "dirty". The server must not attempt to boot into this chaos.
    * In the ASRock BIOS, navigate to `Advanced -> ACPI Configuration`.
    * Find **Restore on AC/Power Loss** and set it strictly to **Power Off**.
3. **The WOL Handoff:** The NETGEAR MS308E must be plugged into the Eaton UPS alongside the NUC. This ensures the network path remains alive. Once grid power returns and the NUC verifies network stability, it securely issues the Wake-on-LAN packet to safely awaken the AI cluster.
