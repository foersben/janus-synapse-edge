# 12. Multi-Tenant Profiles & Privacy Tiers

## 1. Profile Isolation (SurrealDB + Hindsight)

We prevent "Brain-Mixing" by enforcing strict scoping at the memory substrate level.

* **Namespacing:** Every user/profile is assigned a unique SurrealDB Namespace (e.g., `ns: architect` vs `ns: partner`). Agents are provided with scoped RPC credentials that only authorize access to their specific namespace.
* **Hindsight user_id:** Every request to the memory engine includes a `user_id` header. Hindsight strictly filters the vector/graph search to only include nodes belonging to that ID, ensuring personalized context without cross-contamination.

## 2. Sensitivity Tiers & Egress Logic

We categorize workloads to determine if they are allowed to touch the public internet.

* **Tier 0 (Private):** Highly personal or sensitive chats (e.g., Psychologist profile). These are hard-routed to **Local Inference Only (Engine A)**. The LiteLLM config for these users has `egress: block` to ensure zero data ever leaves the local 2.5G backbone.
* **Tier 1 (Professional):** Developer tasks. Allowed to utilize remote LLMs (Claude/OpenAI) via LiteLLM after passing through the PII Masking filter and Hindsight Tag Filter (only passing facts tagged as `privacy: public`).

## 3. Resource Suitability & Priority

All AI reasoning (Engine A & B) occurs on **VM 1 (Tensor Worker)** to access the RTX 5070 Ti and its P-Core allocation. Priority is managed via temporal preemption rather than physical core splitting.

| Component | Status | Multi-Tenant Suitability |
| :--- | :--- | :--- |
| **P-Cores (0-15)** | **Critical** | Hosts all inference. Interactive chats (Priority: System-Critical) instantly preempt background agents (Priority: Background-Yield). |
| **E-Cores (16-25)** | **Support** | Handles the "Orchestration Layer" (LiteLLM, n8n, K3s Control Plane) for all users simultaneously without interrupting GPU compute. |
| **128GB DDR5** | **Superpower** | Allows both a 70B model and 8B models to stay resident in memory via PowerInfer offloading, preventing "Cold Start" lag for users. |
| **RTX 5070 Ti** | **Adequate** | 16GB VRAM is the narrowest point; strict `--mem-fraction-static` fencing is required to prevent OOM when multiple engines are active.
