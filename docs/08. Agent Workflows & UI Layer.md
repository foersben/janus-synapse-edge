# 08. Agent Workflows & UI Layer

*This layer is where we actually interact with the server. Everything beneath this is invisible infrastructure.*

## 1. AnythingLLM (The Daily Driver UI)

Instead of interacting via raw API calls, deploy **AnythingLLM** as a pod in our Kubernetes cluster.

* **Why this UI:** It is the best interface for local RAG (Retrieval-Augmented Generation).
* **Workspaces:** Create dedicated workspaces (e.g., "Coding Lab", "Financials", "Hardware Docs").
* **Document Ingestion:** We can drag and drop massive PDFs or entire ZIP files of codebases into a workspace. AnythingLLM will instantly chunk them and vectorize them into our SurrealDB instance.
* **The Connection:** Point AnythingLLM's LLM provider to our internal **LiteLLM Proxy** IP address. Do not point it directly to `SGLang` or `llama.cpp`.

## 2. The Hybrid Agent Ecosystem

Our autonomous workers are divided by capability and framework.

- [ ] Agent Zero (The Architect & Terminal Operator)
* **Framework:** Agent Zero (v1.9+) with Dockerized `Projects` isolation.
* **Assigned Engine:** Engine A (PowerInfer 70B).
* **Role:** A general-purpose, organic assistant that uses the raw OS terminal as its primary tool. When we assign a complex project, Agent Zero acts as the supervisor, breaking down tasks, utilizing `SKILL.md` standardized capabilities, and delegating sub-tasks to subordinate agents.

- [ ] NemoClaw (The Persistent Executor)
* **Framework:** NVIDIA NemoClaw (Enterprise Agent Platform).
* **Assigned Engine:** Engine B (SGLang 14B-20B NVFP4).
* **Role:** NemoClaw runs as a continuous background service rather than a stateless chat script. It handles the gritty execution: reading files, executing API chains, and running Python scripts exactly as Agent Zero commands.

- [ ] CrewAI (The Role-Based Swarm)
* **Framework:** CrewAI (Replacing the deprecated AutoGen Studio).
* **Assigned Engine:** Engine B (Multiple small 8B models loaded simultaneously).
* **Role:** Used for structured, hierarchical workflows. We define specific personas (e.g., "Senior Python Reviewer", "Security Auditor"). CrewAI orchestrates them sequentially or hierarchically to debate code quality or research topics without getting stuck in infinite conversational loops.

- [ ] NemoVision (The Browser Operator & MCP Server)
* **Framework:** Model Context Protocol (MCP) Server powered by the **NVIDIA Nemovision-4B-Instruct** multi-modal SLM.
* **Assigned Engine:** Isolated to the Outbound DMZ namespace.
* **Role:** The Nemovision-4B model is specifically designed by NVIDIA to visually comprehend desktop UIs. It receives a URL via the MCP bridge, visually "sees" the rendered Single-Page Application, clicks buttons, and extracts data, returning only sanitized text/JSON back to our internal agents
